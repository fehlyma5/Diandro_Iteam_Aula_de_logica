# 📁 Organização do projeto

Mantenha a seguinte estrutura:

```
/
│
├── Aula01/
│   ├── Ex01/
│   ├── Ex02/
│   └── Ex03/
│
├── Aula02/
│   ├── Ex01/
│   ├── Ex02/
│   └── Ex03/
│
├── Aula03/
│
├── Aula04/
│
└── README.md
```

Dentro de cada exercício coloque todos os arquivos relacionados.

Exemplo:

```
Aula02/
└── Ex01/
    ├── fluxograma.png
    ├── algoritmo.alg
    └── algoritmo.py
```

# 📌 Padrão dos exercícios

Utilize nomes simples e padronizados.

Exemplo:

```
Aula03/
    Ex01/

        algoritmo.alg

        algoritmo.py

        fluxograma.png
```

Evite espaços e acentos nos nomes dos arquivos.

---

# 🚀 Como entregar os exercícios

Após concluir um exercício:

1. Salve os arquivos na pasta correta.

2. Faça o commit.

3. Envie para o GitHub.

Exemplo:

```bash
git add .
git commit -m "Aula 02 - Exercício 01"
git push
```

A correção será realizada diretamente no seu repositório.
