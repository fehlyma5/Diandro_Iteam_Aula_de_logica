# Exercício 01 — Cadastro de Notas

**Aula 7 — Vetores e Prática de Programação**

## Enunciado

Crie um algoritmo que declare um vetor para armazenar 5 notas, solicite ao usuário que informe cada nota e, ao final, exiba todas as notas cadastradas na ordem em que foram informadas e em ordem decrescente.

## O que entregar nesta pasta

- `algoritmo.alg`

Evite espaços e acentos nos nomes dos arquivos. Depois de resolver, faça o commit e o push conforme as instruções do README principal do repositório.
