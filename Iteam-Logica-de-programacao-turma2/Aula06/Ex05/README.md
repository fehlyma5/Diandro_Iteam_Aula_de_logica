# Exercício 05 — Caixa Eletrônico

**Aula 6 — Estruturas de Repetição**

## Enunciado

Crie um algoritmo de um caixa eletrônico. Deve solicitar a senha do cliente e, enquanto a senha informada for diferente de 2026, solicitar uma nova tentativa. Quando a senha estiver correta, exiba "Acesso liberado!". Estrutura: ENQUANTO.
