# Exercício 09 — Controle de Acesso da Empresa

**Aula 4 — Variáveis e Tipos de Dados**

## Enunciado

Uma empresa possui três níveis de acesso. Funcionários entram apenas se estiverem identificados E possuírem crachá. Visitantes entram apenas se estiverem acompanhados OU possuírem autorização prévia. Leia: É funcionário? (V/F), Possui crachá? (V/F), Está acompanhado? (V/F), Possui autorização? (V/F) e informe se o acesso foi permitido.
