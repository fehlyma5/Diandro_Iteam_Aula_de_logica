# Exercício 01 — Sistema de Empréstimo

**Aula 4 — Variáveis e Tipos de Dados**

## Enunciado

Uma financeira só aprova empréstimos para pessoas maiores de idade. Crie um algoritmo que leia a idade do cliente e informe se o empréstimo foi aprovado ou negado.

## O que entregar nesta pasta

- `algoritmo.alg`

Evite espaços e acentos nos nomes dos arquivos. Depois de resolver, faça o commit e o push conforme as instruções do README principal do repositório.
