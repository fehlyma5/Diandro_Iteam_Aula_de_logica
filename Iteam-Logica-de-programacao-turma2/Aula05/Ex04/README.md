# Exercício 04 — Calculadora de Áreas

**Aula 5 — Estruturas de Seleção**

## Enunciado

Leia uma opção para calcular a área: 1 – Quadrado (lado × lado); 2 – Retângulo (base × altura); 3 – Triângulo ((base × altura) / 2); 4 – Círculo (PI × raio², use PI = 3,14). Caso o usuário informe uma opção diferente de 1, 2, 3 ou 4, exiba "Opção inválida".
