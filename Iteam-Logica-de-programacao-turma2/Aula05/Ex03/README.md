# Exercício 03 — Faixa de Desconto

**Aula 5 — Estruturas de Seleção**

## Enunciado

Leia o valor da compra e informe o desconto: até R$100,00 → sem desconto; de R$100,01 até R$300,00 → 5%; de R$300,01 até R$600,00 → 10%; acima de R$600,00 → 15%. Ao final, exiba o valor da compra, o percentual de desconto e o valor final.
