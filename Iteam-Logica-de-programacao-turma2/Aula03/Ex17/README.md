# Exercício 17 — Contador de Aprovados

**Aula 3 — Construindo Algoritmos na Prática**

## Enunciado

Leia a quantidade de alunos. Depois leia a média de cada aluno (média ≥ 7 → aprovado). Ao final informe quantos alunos foram aprovados e quantos foram reprovados.
