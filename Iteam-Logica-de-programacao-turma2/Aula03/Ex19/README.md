# Exercício 19 — Caixa Eletrônico

**Aula 3 — Construindo Algoritmos na Prática**

## Enunciado

O usuário possui um saldo inicial informado. Enquanto houver saldo: pergunte quanto deseja sacar; se houver saldo suficiente, realize o saque; caso contrário, informe "Saldo insuficiente". O programa termina quando o saldo chegar a zero ou o usuário informar que deseja encerrar.
