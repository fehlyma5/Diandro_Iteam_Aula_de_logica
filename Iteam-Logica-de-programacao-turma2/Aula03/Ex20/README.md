# Exercício 20 — Pesquisa de Satisfação

**Aula 3 — Construindo Algoritmos na Prática**

## Enunciado

Uma empresa entrevistou vários clientes. Para cada cliente leia uma nota de 1 a 5. A pesquisa termina quando o usuário informar 0. Ao final informe: quantidade de respostas, média das notas, quantos responderam 5 e quantos responderam 1.
