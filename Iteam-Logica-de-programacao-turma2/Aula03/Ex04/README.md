# Exercício 04 — Área do Triângulo

**Aula 3 — Construindo Algoritmos na Prática**

## Enunciado

Crie um algoritmo que calcule a área de um triângulo. Fórmula: área = (base x altura) / 2.

## O que entregar nesta pasta

- `algoritmo.alg`

Evite espaços e acentos nos nomes dos arquivos. Depois de resolver, faça o commit e o push conforme as instruções do README principal do repositório.
